# Dostihy a sázky

Digitální multiplayer verze české deskové hry Dostihy a sázky (2–6 hráčů, i s boty).

## Spuštění

Potřebuješ Node.js 18 nebo novější.

    npm install
    npm start

Hra poběží na http://localhost:3001. Ostatní hráči v síti se připojí na adresu tvého počítače.

## Testy

    npm test
